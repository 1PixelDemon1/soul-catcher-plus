# Soul Catcher Plus 1.3.0.1

Release date: **2026-11-26**. This maintenance release updates the
core and separate Compat addon for all four maintained Forge platforms. It corrects
loader compatibility without adding gameplay features. Fresh builds, archive
audits, and packaged-client startup checks passed.

| Minecraft | Forge build target | Declared Forge minimum | Game Java | Core version |
|---|---|---|---|---|
| 1.16.5 | 36.2.42 | **36.2.26** | 8 | `1.3.0.1+1.16.5` |
| 1.19.2 | 43.5.0 | 43.1.10 | 17 | `1.3.0.1+1.19.2` |
| 1.20.1 | 47.4.28 | 47.1.4 | 17 | `1.3.0.1+1.20.1` |
| 26.3 | 66.1.0 | 66.0.0 | 25 | `1.3.0.1+26.3` |

## Changes from 1.3.0

- **1.16.5:** raise the declared Forge floor from 36.0.42 to 36.2.26 in both
  core and Compat. The build target remains 36.2.42. Older loader/scanner failures
  in the audited Java 8u504 environment motivate this corrected floor; this is not
  a claim that every Java/Forge combination has been tested.
- **1.20.1:** use a no-argument core entrypoint and retrieve the mod event bus from
  the loading context, avoiding a constructor-injection requirement that prevented
  loading on the declared older Forge baseline. The build target remains 47.4.28
  and declared minimum remains 47.1.4.
- **All platforms:** version the core/addon artifacts as 1.3.0.1. Compat accepts
  core **1.3.0.1**, **1.3.0**, and **1.3.0-prerelease** for the matching Minecraft
  version. Network protocol remains **17**; no gameplay or API behavior changes.

Install only the matching runtime JAR for the selected Minecraft version, on
client and server. Creature integrations require the separately installed Compat
addon and selected creature mods/libraries. No creature integration or working
Forge Patchouli build is verified for 26.3. Historical tags, artifacts, and release
notes remain unchanged; no universal mod compatibility or world migration is supplied.

## Artifacts and validation

Files are `soulcatcherplus-1.3.0.1+<minecraft>.jar` and matching `-sources.jar`
files for all four platforms. Only runtime JARs are installed. The prepared core
set and `SHA256SUMS.txt` are in `build/releases/1.3.0.1/core`; the combined
`archive-audit.json` covers both projects.

All **eight** fresh core/addon `build -x test` runs and **16** runtime/sources
archive audits passed, including versions, Forge minima, Java class levels
52/61/61/69, JSON/Mixin resources, and isolation. Compat's ordered exact core
ranges were checked with the Maven implementation from each minimum Forge profile:
all three intended same-Minecraft versions are accepted and another Minecraft
version is rejected.

A fresh **26-run installed-client matrix** used the exact **1.3.0.1 release JAR
bytes**, verified against their hashes, with core alone and core plus Compat:

| Minecraft | Forge versions checked, each in both configurations |
|---|---|
| 1.16.5 | 36.2.26, 36.2.34, 36.2.42 |
| 1.19.2 | 43.1.10, 43.5.0, 43.5.2 |

| 26.3 | 66.0.0, 66.1.0, 66.1.9 |

All clients passed startup and normal shutdown with exit 0, without optional
creature mods or entering worlds. A separate isolated copy of **OccultCraft** on
Minecraft 1.20.1 / Forge 47.2.5 also passed startup and normal exit 0 with both
exact final JARs, without entering a world. These reports are
`.tools/release-1.3.0.1/startup-audit.json` and `occultcraft-validation.json`.

The preceding 26-run compatibility audit used 1.3.0-versioned candidates and
remains separate historical evidence. No new dedicated-server checks, automated
tests, GameTests, UI automation, gameplay, or multiplayer verification ran.
Startup does not certify every modpack feature, native attack, renderer, world
migration, or other Forge/dependency combination.
