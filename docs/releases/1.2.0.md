# Soul Catcher Plus 1.2.0

Release date: **2026-11-10**. Separate core and [Compat](https://github.com/1PixelDemon1/soul-catcher-plus-compat) builds are available for four Forge platforms. All eight runtime JAR builds passed. The 26.3 core is a native Java 25 port; third-party integration availability on that platform is limited.

| 1.19.2 | 43.5.0 | 17 | `1.2.0+1.19.2` |

## Installation and platform scope

Install `soulcatcherplus-<artifact-version>.jar` on both client and server. For supported dedicated integrations, also install `soulcatcherplus-compat-<artifact-version>.jar` on both sides with the exact matching core version. The core requires no creature mod or animation library. Creature mods and their libraries are separate installations, not bundled code/assets.

Use separate Minecraft profiles/worlds. All four core builds use protocol **12**, but equal protocol numbers do not enable cross-Minecraft connections. Older addons are not automatically compatible with core 1.2.0. The 1.19.2 build/minimum is now Forge **43.5.0**; historical 1.0.0 artifacts built for 43.5.2 remain unchanged. Forge 1.20.1 retains **47.4.28**. Java 17/Jabel compiles the 1.16.5 Java 8 build; Jabel remains compile-only.

The 1.19.2/1.20.1 ports bring forward the 1.16.5 1.1.0 features: Raven and Courier, scrolls and rare chest loot, animated cages, local appearance controls, offline persistence, and Teleport/revised return commands. The 26.3 port adapts queued rendering, SDL input, item-component NBT, dynamic enchantments, and current recipe formats to native APIs. Build/startup results are not comprehensive gameplay parity certification.

## Soul Shaman and Forgotten Souls

**Soul Shaman** is a passive **8-HP** Forgotten Soul, unlocked through a typed scroll rather than ordinary combat capture. The existing **2% chance per eligible root chest-table generation** is unchanged; a successful roll now chooses Raven, Courier, or Shaman equally. Creative presets include all three. Normal summon pricing, cage energy, species limits, and recovery still apply after unlocking.

While within **six blocks of its eligible owner**, the Shaman begins a cast at **140-tick intervals**. The 36-tick cast applies its aura at tick 18, rechecking owner eligibility at impact. **Strength I and Regeneration I last 160 ticks** and apply to the owner and eligible active souls within six blocks of the **owner**. Unrelated players/pets are excluded. Native effect merging preserves stronger effects and native immunities, including undead regeneration rules; the aura does not guarantee direct healing for every mob type.

The synchronized cast start lets observers joining mid-cast see the current animation phase. Forgotten Soul models share new amulet artwork. Editable model sources, textures, and export tooling accompany the artwork.

## Optional Patchouli guide

An English/Russian guide covers capture, cage energy/refunds, collections/forms, commands, equipment, enchantments, scroll loot, and Forgotten Souls. Patchouli is optional and installed separately; the core has no linked Patchouli Java dependency.

| Minecraft | Patchouli baseline | Release evidence |
|---|---|---|
| 1.16.5 | 1.16.4-53.3 | Client startup and guide resource loading passed |
| 1.19.2 | 77 | Client startup and guide resource loading passed |
| 1.20.1 | 85 | Client startup and guide resource loading passed |
| 26.3 | No matching published Forge build identified | Guide availability is not claimed |

On the older three platforms with a matching Patchouli build installed, players receive the guide on first eligible login, including existing worlds. Persisted delivery state prevents repeat grants. A full inventory drops an owner-assigned book; failed delivery can retry on a later login. The conditional shapeless recipe uses one book and one soul sand, and the guide appears in the creative tab. Delivery/recipe are skipped without Patchouli.

Each language has 15 guide entries; the two language views contain **38 JSON resources** in total. Text is paginated independently with title/footer space reserved, and literal percent signs escaped for Patchouli translations. Recipe pages reference actual crafting/smithing recipe IDs. Startup/resource loading passed, but resource-pack fonts, unusual key labels, and every page's visual layout still require gameplay inspection.

## Branding and integration separation

The transparent originals in `art/branding` supply the new lettered presentation banner, derived 256-pixel mod icon, and 32-pixel creative icon. The original PNGs and transparency are preserved.

Generic public extension APIs stay in the core. Core builds do not load Compat sources, scripts, or JARs. Compat uses a configured installable core JAR, without an adjacent source dependency. Its dedicated Ferrous Wroughtnaut activation/appearance adapter and soul profile have been removed; Mowzie area-attack ally filtering remains. Twilight Forest summoner/master corrections and Aquamirae music handling are version-specific. Aquamirae 7.x is not verified by the inspected 1.20.1 6.x correction.

For 26.3, the addon reached title/resource reload with the core and **no creature mods**. The release's Modrinth lookup found no Forge 26.3 releases for Mowzie's Mobs, Aquamirae, or Patchouli. An official Twilight Forest Forge 26 build was not verified. Therefore, the 26.3 addon is a build/load baseline, not proof that those integrations work on that platform. No universal compatibility claim is made.

## Saved data and migration limits

Back up existing worlds. The native 26.3 SavedData path has a fallback for a legacy flat `soulcatcherplus.dat` ledger when the new collection file is absent, including data-fixing nested entity snapshots. It preserves the original legacy file and does not silently restore stale data over a present unreadable new file.

That collection fallback is not a universal Minecraft-world migration tool. Matching item/entity IDs do not establish safe transfer between all game versions, mod registries, or custom entity snapshots. Use separate profiles and retain backups. Existing release artifacts, tags, and historical notes remain unchanged.
