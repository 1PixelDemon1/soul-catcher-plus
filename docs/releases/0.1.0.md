# Soul Catcher Plus 0.1.0+1.20.1

Initial playable prototype for Minecraft Java 1.20.1. Mark an enemy with the Soul Scythe, defeat it, collect its soul, and spend soul energy to summon a spectral companion.

## Included

- A persistent collection and energy balance owned by the player rather than the scythe.
- Harvest/command modes and a collection screen in English and Russian.
- Follow, wait, guard, attack, and recall commands for one companion or a group.
- Summon costs, a six-slot capacity, one active instance per soul, and a 60-second recovery cooldown after companion defeat.
- Original mob restoration, allied-damage checks, stale-summon rejection, and suppression of duplicated companion loot and energy.
- Spectral rendering for standard living-entity renderers.
- An optional Ferrous Wroughtnaut adapter that keeps native attacks and activation while excluding allies from area-target queries. Its summon costs 200 energy and four capacity slots.
- Experimental public adapter/event/visual interfaces and datapack balance profiles. See [API documentation](../API.md).

## Requirements and installation

Use Minecraft **1.20.1**, Forge **47.4.28**, and Java **17**. Install `soulcatcherplus-0.1.0+1.20.1.jar` on both client and server.

The base mod works without Mowzie's Mobs. To use the Wroughtnaut integration, install **Mowzie's Mobs 1.8.2 for 1.20.1** and **GeckoLib 4.8.3 for Forge 1.20.1** separately. Third-party code and assets are not bundled.

Right-click an enemy with the scythe in Harvest mode to mark it. Collect its remnant after victory; Shift + right-click opens the collection. See the [README](../../README.md) for crafting, controls, and development commands.

## Known limitations

This is a pre-1.0 prototype, not a production-readiness claim. Balance and interface layout remain provisional. The Wroughtnaut retains its native special defense and boss bar, making it particularly powerful.

The default companion implementation targets ordinary goal-based AI. Brain-based entities, custom encounter phases, conversions, summoned minions, and unusual renderers can require dedicated adapters. Compatibility with arbitrary modpacks is not guaranteed.

Shaders, custom rendering layers, extended play sessions, and two real multiplayer clients have not been fully tested. Public interfaces may change before 1.0. There are no ports to other Minecraft versions or loaders, and no companion progression system yet.

No major-version tag is created for this 0.1.0 prototype.
