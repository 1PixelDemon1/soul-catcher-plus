# Soul Catcher Plus 1.0.0 — validation record

Validation date: 2026-10-31. This is a build, package, source and dependency-bytecode review, not a new gameplay certification.

## Source revisions

- Forge 1.16.5 core and addon: `cf81e8abfbbd5d444e7cd23b48a8d9507fcb1346` on `develop`.
- Forge 1.20.1 core and addon: `980af6b2ceb4fa57489c7e555c5ea76803c4a7f2` on `codex/forge-1.20.1`.
- The release documentation and promotion commits follow these source revisions; no gameplay code changed afterward.

## Completed checks

- Both version-specific Gradle `build -x test` tasks completed successfully, including `reobfJar` and `reobfCompatJar`.
- The 1.20.1 development QA command compiled separately into an isolated output directory. It was not executed or included in release JARs.
- All four runtime JARs passed archive CRC, JSON parsing, expanded version metadata and core/addon class-isolation checks.
- 1.16.5 classes target Java 8 (class major 52); no Java Record runtime or Jabel classes are bundled. 1.20.1 classes target Java 17 (major 61).
- Runtime artifacts contain no QA command, GameTest classes or nested third-party JARs. Both core artifacts include five advancements, Supreme scythe resources and the medium-soul logo.
- Read-only quality review found no remaining actionable release blockers after fixes to collection payload size, the 1.16.5 Mowzie dependency range, the 1.20.1 medium-soul atlas source and its follow-goal repath timing.
- Mowzie's Mobs 1.5.27 (1.16.5) and 1.8.2 (1.20.1) activation methods, fields, NBT keys and four area-target mixin descriptors were checked against actual JAR bytecode.
- Aquamirae 6.1.2 and 6.4.0 music-controller bytecode was inspected for the 1.20.1 addon. Its hook uses the outer client controller and a client tick listener; it does not assume the legacy 1.16.5 ambient-controller layout.
- Forge 1.20.1 music mixin targets and official/SRG aliases were checked against the mapped game JAR/mappings.

## Validation limits

The user explicitly requested no client launch at completion. Neither version was launched for this release pass. Automated tests, GameTests and UI automation were not run. Earlier manual development feedback is not evidence that the new 1.20.1 port has been gameplay-tested. Other creature-mod versions, Aquamirae 7.x music internals, and universal mod compatibility are not certified. Compiler deprecation warnings on Forge 1.20.1 remain; compilation succeeds.

## Artifacts

The local distribution is under `build/releases/1.0.0`, with separate `1.16.5` and `1.20.1` directories. `SHA256SUMS.txt` and `artifact-audit.json` identify the packaged files. Install only the pair matching the selected Minecraft version; the compatibility addon requires the exact matching core version. Creature mods and their own dependencies are installed separately.
