## Range and preview APIs

`SoulAdapter.followRange(mob)` controls the owner-centered Follow/Aggressive combat/return range. Ordinary companions keep the **40-block** default. Hard teleport starts beyond the larger of **64 blocks** and the adapter range; invalid/non-finite or sub-four-block values fall back to the default. Existing stuck-return checks remain. Compat uses this API for a **100-block** Ice and Fire dragon range.

`SoulPreviews.mark/isPreview` identifies detached collection models, allowing integrations to choose GUI poses separately from live animation. Previews stay outside the world and are not AI-ticked. Both APIs are available on all four ports through their native entity types.

## Companion corrections

On **1.19.2, 1.20.1, and 26.3**:

- Perched Ravens use the owner's previous/current body/head rotation samples and wrapped head yaw, correcting stale turns and angular-wrap artifacts.
- Withers discard stale idle navigation, keep gravity disabled, hold a stable distance/side from the owner, and interpolate rendered side-head rotations from native tick samples.
- Warden companions use common command targets with native Brain melee/Sonic Boom and cooldowns. Captured anger/listener state is cleared; autonomous digging, sniffing/roaring, vibration-driven target changes, and the friendly darkness pulse are skipped. Native ally checks remain.

There is no Warden on the 1.16.5 target. These changes preserve platform-specific native APIs rather than introducing that mob into the older game.

## Patchouli and installation

The optional Patchouli dependency no longer imposes an artificial minimum build. Install a Patchouli artifact whose own metadata supports the selected Minecraft/Forge version. The guide uses data/item lookup without linked Patchouli Java classes. Previous 53.3/77/85 guide baselines remain historical examples, not hard minimums or fresh results. Forge Patchouli support on 26.3 is unverified.

Install the core on both client and server for the chosen Minecraft version; install matching Compat on both sides for its dedicated corrections. Creature mods/libraries are separate dependencies. Compat adds Ice and Fire and expanded Twilight Forest corrections on the older three platforms; see its version-specific matrix. Creature integrations on 26.3 are not certified. Aquamirae 7.x and arbitrary custom AI/renderers are not universally supported.

Both projects use Forge **66.1.0** on 26.3. Historical addon 1.2.0 artifacts keep their original 66.1.5 requirement. Use matching core/addon versions, separate game profiles/worlds, and backups; no universal world migration is provided. Routine core builds remain independent of addon sources/JARs.
