# Optional Patchouli guide

Install the matching Forge Patchouli build alongside the core mod on the
relevant game sides: 1.16.4-53.3-forge for Minecraft 1.16.5, 1.19.2-77-forge for
1.19.2, or 1.20.1-85-forge for 1.20.1. It is not bundled and is not required to
load or compile the core. No Patchouli Java classes are referenced; the book
uses its guide-book item and data format.

The guide ID is `soulcatcherplus:soul_guide`. Players receive one on their first
login with Patchouli present, including existing worlds. `PlayerPersisted`
records successful delivery across logins and respawns. A full inventory drops
the owner-assigned book nearby; a failed drop leaves delivery eligible for the
next login. Creative overflow cannot erase a dropped guide during pickup.

The conditional shapeless recipe uses one book and one soul sand. Without
Patchouli the recipe is skipped and no guide is given. The book also appears
in the mod's creative tab when Patchouli is installed.

The guide is written as an in-world field book, covering capture, energy,
the bestiary, orders, recovery, equipment, enchantments and the three Forgotten
Souls. It deliberately leaves exact balance numbers for players to discover.
The separate Commands & debugging category documents the production
`/soulcatcher energy` and `/soulcatcher scroll` commands, permissions, arguments,
modded IDs and practical examples. QA-only commands are omitted.
Key instructions identify their defaults. English and Russian are fully authored
separately, including the Russian names of souls and enchantments.

The primary 1.16.5 guide has 18 entries and five categories: 46 localized content
JSON files plus the book definition. Its commands chapter includes the new scroll
command, currently implemented on that branch. English and Russian text lives
in the normal language files.
Patchouli content is under `data` on 1.16.5 and under `assets` with
`use_resource_pack` on the newer ports. The generator reads `minecraft_version`
to choose the layout and creative tab ID. Forge 26.3 retains these resources for
a future integration; a compatible Patchouli runtime has not been verified there.
The first-soul entry uses the existing small-remnant PNG as a Patchouli resource
icon; Commands & debugging uses the vanilla experience bottle item.

The Drawings entry has four recipe-only pages, with two recipes per page and four
per spread. The first spread covers iron/diamond scythes and cages; the second
pairs netherite smithing upgrades with supreme crafting recipes. Prose is kept
in other entries so translated text cannot shift a recipe to another spread.
The replacement book recipe has its own entry. Crafting and smithing pages
reference all nine real recipe IDs, not copied grids.
The item uses the 16x16 teal book icon in the runtime item textures. Its approved
source artwork and the other asset inputs are listed in [ASSETS.md](ASSETS.md).

Edit `scripts/generate_soul_guide.py` and run it to regenerate the catalog,
language entries and both language-folder views. No recipe or gameplay rules
are generated by that script.

Each language is paginated independently using the vanilla font advances
in `scripts/soul_guide_font.json`. Text pages reserve space for titles and the
footer, and literal percent signs are escaped for Patchouli's translation format.
The landing page has a shorter introduction; the opening entry continues it.
Resource packs with different fonts may need a separate visual check.

For a manual integration run, add `-PwithPatchouli` to the regular development
client command. This flag adds only a runtime dependency. The ordinary build
and standard development configuration remain independent of Patchouli.
