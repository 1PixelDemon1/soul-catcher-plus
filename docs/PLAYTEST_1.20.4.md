# Soul Catcher Plus — сборка для Minecraft 1.20.4

Требуются **NeoForge 20.4.253** и **Java 17**. Это отдельный экспериментальный порт
Soul Catcher Plus из ветки `codex/neoforge-1.20.4`, не новый релиз мода.

В папке `mods`:

- Soul Catcher Plus `0.2.0+1.20.4`, с текущими механиками ветки разработки.
- [Advent of Ascension 3.7.7](https://www.curseforge.com/minecraft/mc-mods/advent-of-ascension-nevermine/files/5285649) — Release.
- [Twilight Forest 4.4.2276](https://www.curseforge.com/minecraft/mc-mods/the-twilight-forest/files/5320183) — Release.

AoA уже содержит GeckoLib 4.4.4, SmartBrainLib 1.14, TslatEffectsLib 1.8.5,
Patchouli 1.86 и HSQLDB 2.7.2. Дополнительно скачивать их для этой сборки не нужно.
Статус Release относится к файлам сторонних модов, а не к полноте их контента.

## Установка

1. Создайте отдельный профиль Minecraft **1.20.4** с **NeoForge 20.4.253**.
2. Скопируйте папку `mods` из архива в папку этого профиля.
3. Для совместной игры установите те же три JAR у обоих игроков и на сервере.
4. Создайте новый мир для проверки порта.

Начните с крафта косы и клетки душ. Клетка работает во второй руке и хотбаре;
вторая рука приоритетнее. **O** — коллекция, удержание **R** — колесо приказов.
Для открытия меню держите косу в одной из рук.

Служебная `/soulcatcherqa` доступна только в клиенте разработки с `-PgameTests`.
В устанавливаемый JAR и этот архив она не включена. Для настройки энергии
оператор может использовать `/soulcatcher energy <число>` при наличии клетки.

Совместимость поведения всех мобов AoA и Twilight Forest не проверена.
Исходный код Soul Catcher Plus распространяется по MIT; сторонние JAR сохраняют
лицензии и авторство своих проектов. Архив подготовлен для локальной проверки.
