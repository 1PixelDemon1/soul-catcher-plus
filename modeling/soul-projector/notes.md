# Soul Projector

Approved size: 16 x 8 x 16 Blockbench units (one half block). Both skins share
eleven axis-aligned cuboids: a recessed foot, slab body, four flush rim pieces,
an inset lens and four thin emitter edges. The unseen back matches the front.

The dark skin uses vanilla polished blackstone; the light skin uses quartz.
The lens and cyan edge reuse existing authored cage materials. Textures are
embedded in each `.bbmodel`. `generate_model.py` rebuilds both plans/projects.

The scroll is stored inside and has no external geometry. The projected mob is
a separate client-only display, not part of these bounds or a real summoned mob.
