# Soul guide item icon

Generated using the built-in imagegen tool. The third version follows the
vanilla Minecraft book silhouette supplied by the user: teal cover, opaque
light pages and a small cyan seal. The first two concepts were rejected and
are retained here as references, not used by the game.

The final original is `guidebook-source-v3.png`. The runtime asset is
`src/main/resources/assets/soulcatcherplus/textures/item/soul_guide.png`, reduced
to 16x16 using nearest-neighbor sampling while retaining alpha. No pixels were
painted by code. The reference book silhouette is from Minecraft (Mojang).
